# Decisions and extras

The README carries a ten-row summary. This page is the longer index: one row per headline decision with the alternative I turned down, and then every item I built beyond the brief with its justification, cost and status. The reasoning itself is in the ADRs, linked on each row. Who decided what is in each ADR's `Deciders` line; where it only says "engineering", the proposal was drafted by an agent and I accepted it.

## Headline decisions

| Decision | Rejected alternative | Why | What it costs | ADR |
|---|---|---|---|---|
| A partial unique index on `(doctor_id, starts_at) WHERE status = 'booked'` decides double booking | `EXCLUDE USING gist`, SERIALIZABLE with retries, advisory locks, check-then-insert | It is the smallest mechanism the engine enforces itself, so it holds across instances with no coordination | Correct only for fixed, aligned 30-minute slots; variable lengths need the `EXCLUDE` form | [0003](../adr/0003-double-booking-partial-unique-index.md) |
| Slots are computed from working hours | A materialized `slots` table, an RRULE engine | The brief's working hours stay the only source of truth, so nothing drifts | No slot row to lock, so uniqueness lives on the appointment | [0004](../adr/0004-computed-slots.md) |
| FastAPI is the single system of record | Django REST Framework; FastAPI plus a Go service in the write path | One runtime, typed end to end, and the OpenAPI document generates the client | Python cold starts; no latency target was measured | [0002](../adr/0002-fastapi-single-system-of-record.md) |
| UTC `timestamptz`, the clinic zone as data, an injected clock | The zone in environment config; naive local timestamps | A second clinic needs no code change, and tests pin time | An extra join to read the zone | [0005](../adr/0005-time-and-timezone-model.md) |
| RFC 9457 problem details with a closed code catalogue | FastAPI's default `{"detail": ...}`; a custom envelope | Clients need a stable machine-readable `code`; the brief asks for correct status codes | A typed exception hierarchy to maintain, checked by a test against `docs/api-errors.md` | [0006](../adr/0006-problem-details-error-model.md) |
| REST with OpenAPI 3.1, and a client generated from the contract | tRPC, GraphQL, gRPC | The brief says REST; tRPC needs a TypeScript server; GraphQL hides status codes | Type safety comes from codegen and a CI drift gate; the generator is 0.x and pinned | [0007](../adr/0007-api-style-rest-openapi.md), [0011](../adr/0011-openapi-codegen-contract.md) |
| Reschedule is one in-place `UPDATE` under `SELECT ... FOR UPDATE` | Cancel and reinsert; an unlocked conditional update | The appointment id stays stable and the old slot frees atomically | A swap can end with both requests rejected after one retry | [0008](../adr/0008-appointment-lifecycle-and-reschedule.md) |
| An idempotency key stored on the appointment row, with a request fingerprint | No idempotency; a separate table of stored responses | A lost response must not tell the real booker they lost the slot, and the replay must not need a second store | A key is bound to one doctor and time; reuse with a different body is a 422 | [0013](../adr/0013-idempotency-keys.md) |
| Cloud Run is IAM-only behind a Vercel proxy, in `us-east4` beside Neon in `aws-us-east-1` | Cloud Run in `africa-south1` or `europe-west3` with Neon in Frankfurt; Cloud SQL | I set a $0 rule, and egress to Kenya is billed from byte 0 outside North America; four to six database round trips per booking need the API beside the database | A longer hop for Kenyan users (an estimate, not measured); about $0.34 a month on the shared billing account | [0014](../adr/0014-hosting-region-and-cost.md), [0023](../adr/0023-zero-cost-edge-front-door.md) |
| Two database roles: an owner for migrations and an app role with no DDL rights | One role for everything | A compromised service cannot change the schema | Two secrets and two service accounts | [0015](../adr/0015-database-roles-and-migrations.md) |
| CircleCI, keyless OIDC to workload identity federation, promote by tag after a smoke test, roll back automatically | Cloud Build; a long-lived service-account key | No long-lived GCP credential exists, and only a smoke-tested revision gets traffic | `VERCEL_TOKEN` is long-lived; a main pipeline takes about 10 to 12 minutes (an estimate in the ADR) | [0016](../adr/0016-cicd-circleci-keyless-deploy.md) |
| Real Postgres in every test, a race harness that must fail without the index | Mocked repositories on SQLite | A mock cannot show a unique violation under contention | Slower suites; a compose database in CI | [0018](../adr/0018-testing-strategy.md) |
| Public API stays unauthenticated; patients and staff sign in with Google in the web apps | Mandatory auth on the API; optional bearer auth | The brief's endpoints and Swagger "Try it out" have to work as written | An IDOR on the public API, disclosed in the README | [0012](../adr/0012-identity-and-abuse-controls-deferred.md), [0024](../adr/0024-google-sign-in-with-better-auth.md) |
| Better Auth with stateless session cookies; roles looked up on every request | Auth.js v5 beta; roles in the cookie; an email list in an environment variable | Maintained, database-free sessions, and a revoke takes effect on the next request | One table lookup per request; cookies cannot be revoked early | [0024](../adr/0024-google-sign-in-with-better-auth.md), [0030](../adr/0030-staff-roles-and-access.md) |
| Server actions call the API, with one reCAPTCHA check per action | Browser calls through the proxy | No browser code holds a credential, and the human check runs on the server | The public `/api` proxy is not covered by the check | [0029](../adr/0029-booking-flow.md) |
| Two apps in one pnpm workspace | One app with an `/admin` route group; two repositories | Separate auth surfaces and deploys without publishing shared packages | Two Vercel projects to keep in step | [0027](../adr/0027-two-apps-in-a-workspace.md) |
| Plain JSON logs with a `request_id` and no PII | OpenTelemetry to Cloud Trace; Sentry | Smallest thing that lets a problem body lead to a log line, within the free tier | No traces, no alerting beyond the cost checks | [0019](../adr/0019-observability.md) |
